## 1.2.98：控制能力与绑定

已实现：

1. 单一管理员以platform/account/subject归属，不按昵称合并。显式GUI绑定、解绑、旧微信管理员预填、损坏绑定显式恢复。
2. 绑定后才允许Agent修改配置；旧方案卡应用/撤销、技能与任务写操作沿用同一绑定要求。原控制台不受Agent未绑定影响。
3. 可撤销、分能力、可过期的bridge凭据，磁盘只存摘要。管理员换绑代次变化令旧凭据失效。握手报告真实程序、账号、人设与能力，不把数据库可读当作登录或发送成功。
4. 按操作名登记现有HTTP接口，复用其校验和业务锁。没有任意路径/URL转发，没有管理员自授权和直接发微信接口。审计不保存请求正文；状态读取不带聊天原文。
5. 写操作按request_id持久登记；重复请求只读已有结果，不重复执行。取消/断电后未知结果不重做。登记锁不跨模型等待，停止不排在慢测试后面。
6. 修复旧Agent切人设只改内存的问题，复用运行时持久切换及撤销。

源码验证：1810项测试通过，1项符号链接权限跳过；源码后台和HTTP自检通过。冻结和覆盖升级结果以该版本发布目录的验收记录为准。
