# 插件分层清单（1.3.0 基线审计）

> 1.2.86 调整：`sticker_admin`/`sticker_memory`/`sticker_cadence` 升为基础插件（用户反馈"机器人不发表情了"——分层把配图链路划走后功能凭空消失）。
> 1.2.75 调整：`image_library`、`group_summary` 升为基础插件（配图与本地日报是常用功能，且被 GUI 自检直接引用），基础 24 / 市场 8。

> 审计时间：2026-10-23　基线版本：**1.2.71**　插件总数：**32**
> 审计方式：`PluginManager` 实机加载后读取 `META.id / META.name / settings.enabled`

## 一、划分原则

1. **核心配置面必须内置**（`src/plugin_policy.py` 的 `CORE_PLUGINS`）：管理员、私聊管理、关键词唤醒、群聊监控、长期记忆、群聊控制。它们决定"能不能回、回给谁"，缺一个控制台就不可用。
2. **回复质量的默认链路内置**：点名判定、连发合并、防复读、去重、跟聊、秒回、token 节流。
3. **本地能力内置**：OCR、识图、语音转文字（都不出本机）。
4. **可选的体验增强进市场包**：主动发言、配图节奏、表情收集与管理、睡眠/极简/接梗等。
5. **红线插件不进市场包**：主动外发、面板点击、批量转发类一律不提供下载（`src/plugin_policy.py` 的 `RETIRED_PLUGINS` 继续禁止加载）。

## 六、注意

- 计划原文里的 `mention_nudge_guard`、`quote_reply` 在本仓库属 **RETIRED_PLUGINS**（已退役、禁止重新加载），因此基础清单用现有等价能力替代（点名判定用 `addressee_guard`，引用回复不提供）。
- 任何分层都不能让"默认关闭"的插件在冻结版里被误启用；`default_settings` 保持原值。
