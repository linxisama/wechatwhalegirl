# 鲸鱼娘 · 微信控制台（WhaleGirlWeChat）

> 跑在自己电脑上的微信聊天机器人：收消息、接模型、按你写的规则回复，
> 全部数据留在本机，随时可以一键停。

## 这是什么

一个单机微信机器人控制台。它**不改微信客户端、不注入进程、不上传聊天记录**：

- **收消息**：只读微信本地 SQLite 数据库的增量，不写微信任何文件；
- **发消息**：桌面界面自动化（剪贴板粘贴 + 发送键闸门多证据校验 + 结果确认），
  每一条都要过「确定还是当前会话」的校验才会按键；
- **管理**：九个页签的控制台（控制台 / 设置 / 人设 / 插件 / 对话与记忆 / 机器人管理 /
  外观 / Agent / 关于作者），配置、对话、记忆都在你自己的数据目录里。

不想连真微信时，把「微信后端」切到**模拟模式**：界面、插件、流程都能跑，但不会真的发消息。

## 主要功能

| 能力 | 说明 |
| --- | --- |
| 微信接入 | 微信 4.1.x 桌面版；接收走只读数据库增量，发送走界面自动化，失败一律 fail-closed |
| 模型 | 任意 OpenAI 兼容 / Anthropic Messages 接口；也可以接 DeepSeek Harness（DSH）当主聊 |
| 插件 | 32 个内置插件，逐项开关与调参；另有**可选插件包**（手动安装，主程序不会自动装） |
| 记忆 | 长期记忆、对话摘要、防复读；DSH 作答时可注入本机长期记忆 |
| 语音 / 识图 | 本地 faster-whisper 转写、Windows 自带 OCR 识图 |
| 隔离通道 | 可选把微信装进 Windows 沙盒，机器人跑在沙盒里，与主机数据隔离 |
| 自检 | 「兼容性自检」读取系统版本 / 缩放 / 微信版本 / OCR / 沙盒能力，给出能直接照做的建议 |
| 自动更新 | 检查更新 → 下载 → SHA256 校验 → 调安装包 → 保留配置和历史；校验失败绝不安装 |

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 1903 及以上 / Windows 11（64 位） |
| 微信 | 微信 4.1.x 桌面版（登录机器人账号） |
| 权限 | **管理员权限**启动控制台：微信 4.x 的发送键需要管理员权限，否则「能收不能发」 |
| 源码运行 | Python 3.12（仓库自带依赖清单与一键安装脚本） |
| 可选 | Windows 沙盒（专业版 / 企业版 / 教育版），用于隔离运行 |

## 安装（普通用户）

1. 打开 Releases 页，下载最新的 `WhaleGirlWeChat-Setup-<版本>.exe`
   （同目录的 `.sha256` 是校验文件，可选核对）；
2. 双击安装 —— **不需要**管理员权限安装，默认装到 `%LOCALAPPDATA%\Programs\WhaleGirlWeChat`；
3. 用桌面/开始菜单里的「鲸鱼娘 微信控制台（管理员启动）」启动；
4. 在「设置」里填模型地址 / Key / 模型，选微信后端，保存；
5. 「控制台」页点「启动机器人」，再用小号给机器人发一条消息，看「消息与回复」有没有回复。

升级：直接装新版安装包即可覆盖安装，**配置、历史对话、记忆都会保留**，旧程序会留成
`WhaleGirlWeChat.prev.exe` 供回滚。卸载走「应用和功能」，卸载不会删你的数据目录。

## 源码运行

```text
1) 双击「一键安装依赖.bat」           建 .venv-wechat 并装依赖（3-8 分钟）
2) 双击「以管理员身份启动控制台.bat」  提权启动
3) 设置页填接口 → 保存 → 控制台页「启动机器人」
```

命令行等价写法：

```powershell
py -3.12 -m venv .venv-wechat
.\.venv-wechat\Scripts\pip install -r requirements.wechat.txt -r requirements.gui.txt
.\.venv-wechat\Scripts\python wechat_gui.py
```

## 可选插件包

`plugin-packs/` 下每个文件夹是一个插件包，含 `plugin.json`（名称 / 版本 / 入口 / 依赖 /
兼容版本 / 能力 / 数据用途）、`plugin.py` 薄封装、`README.md` 与 `settings.example.json`。

- 主程序**只加载你手动放进去的包**，不会自动下载、自动安装、自动启用；
- 在「插件」页点「插件包」可以安装（目录或 zip）、启用 / 禁用、移除；
- 包缺失、清单不合法、版本不兼容、加载报错都只会给出中文提示，不会让控制台崩溃；
- 把 `plugin-packs/` 整个删掉，主程序仍能正常启动（只剩核心插件）。

详细步骤见 [控制台操作指南.md](控制台操作指南.md)。

## 自动更新

- 「控制台」页「检查更新」，或启动后自动检查（可在设置里关）；
- 更新源默认是 GitHub Releases，也可以填自己的地址（`update.feed_url`）；
- 下载后先用 SHA256 校验，校验不通过**不会**调用安装包；
- 安装前会提示「安装会关闭控制台并重启」，安装包本身保留用户数据。

## Windows 沙盒隔离通道（可选）

在「控制台」页点「Windows 沙盒」，控制台会：检测系统类型与沙盒功能状态 → 未启用时引导
用 DISM 启用（需要 UAC，可能需要重启后继续）→ 创建隔离通道（共享目录 + 会话配置）→
显示通道状态。家庭版等不支持的系统会明确提示并提供替代方案（本机直连）。禁用与回滚命令
在同一个面板里给出。

## 接入 DeepSeek Harness（DSH）

「Agent」页「DSH 一键连接」：刷新连接器 → 把工作台 MCP 插件写进 DSH 配置 → 让新会话默认
就能连上控制台。连接状态、最近一次错误、超时与自动重连都在面板里可见。

## 数据与隐私

- 数据根：`%LOCALAPPDATA%\WhaleGirlWeChat`（配置、对话、记忆、日志）；
- 密钥在本地加密存储，**不会**写进日志；日志里的会话名只保留前 8 个字符，回复正文不落盘；
- 后端只监听 `127.0.0.1`，拒绝所有非本机请求；
- 仓库里不含任何密钥、令牌、聊天记录、构建缓存。

## 安全边界与封号风险

这个项目刻意**删掉了有封号风险的功能**（群发、主动加人、朋友圈等），只做「收到消息再回复」。
仍然请注意：任何界面自动化都有风险，用小号、控制频率、不要用它做营销。
详见 [封号风险与功能取舍.md](封号风险与功能取舍.md)。
